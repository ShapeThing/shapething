# The ShapeThing widgets

Widgets provided by ShapeThing. We think these are complementary to SHACL UI.

## Editors (`shui:editor`)

| Widget             | Use case                                                                      |
| ------------------ | ----------------------------------------------------------------------------- |
| `st:AddressEditor` | Structured `schema.org` postal-address entry, backed by live geocoder search. |
| `st:IconifyEditor` | Searchable icon picker for [iconify icons](https://iconify.design/).          |

## Viewers (`shui:viewer`)

| Widget             | Use case                                                              |
| ------------------ | --------------------------------------------------------------------- |
| `st:AddressViewer` | Read-only display of a `schema.org` postal address                    |
| `st:IconifyViewer` | Renders the icon named by an iconify-datatyped value.                 |
| `st:MapViewer`     | Plotting every value of a geo-valued property on one interactive map. |

## Facets (`st:facet`)

Similar to `shui:editor`/`shui:viewer` but then for the facet mode.

| Widget                  | Use case                                                                                                                                                  |
| ----------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `st:CategoryFacet`      | Filtering by a property whose values are drawn from a fixed/enumerable set, with optional live per-option counts (`Environment.enableFacetOptionCounts`). |
| `st:SubClassFacet`      | Filtering by a class drawn from a `sh:rootClass` taxonomy, rendered as a nested tree (any node, not just leaves, is selectable).                          |
| `st:TextSearchFacet`    | Free-text contains-match filtering across a property's values.                                                                                            |
| `st:NumberRangeFacet`   | Filtering a numeric property by min/max range.                                                                                                            |
| `st:DateRangeFacet`     | Filtering an `xsd:date` property by min/max range.                                                                                                        |
| `st:DateTimeRangeFacet` | Filtering an `xsd:dateTime` property by min/max range.                                                                                                    |

## Groups (use these IRIs instead of sh:PropertyGroup)

Not scored — selected by direct `rdf:type` match against the `sh:PropertyGroup` node itself
(`widgets/registry.ts`'s `getGroupWidget`).

#### `st:CollapsiblePropertyGroup`

Renders member properties inside a collapsible `<details>` (open by default) instead of the
default flat rendering.

#### `st:HorizontalPropertyGroup`

Renders member properties laid out in a row (flex, wrapping) instead of the default stacked
column, for a small set of properties that read naturally side by side (e.g. a name group's given
name + family name).
